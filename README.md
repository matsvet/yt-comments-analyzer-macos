# YT Comments Analyzer

Простое нативное macOS-приложение: забирает комментарии видео YouTube по API-ключу,
даёт быстрый поиск по тексту и авторам, навигацию по тредам (от ответа к родоначальнику
и раскрытие веток под корнем) и показывает лайки. Данные кэшируются локально.

## Требования

- macOS 14+
- Swift 6 / Command Line Tools (полный Xcode не нужен)
- Ключ YouTube Data API v3 (Google Cloud Console -> APIs & Services -> Credentials,
  включить «YouTube Data API v3»)

## Запуск (разработка)

```bash
swift run YTComments
```

В приложении:
1. Нажать «API-ключ» внизу боковой панели, вставить ключ. Настройки сохраняются автоматически.
2. Вставить ссылку на видео (или ID) в поле «Новое видео» -> «Загрузить».
3. Искать по ключевым словам; клик по результату открывает весь тред справа
   (корень + ответы, найденный комментарий подсвечен).

## Сборка .app для двойного клика

```bash
./build_app.sh
```

Бандл `YT Comments Analyzer.app` появится в корне проекта — открывается из Finder
двойным кликом. Скрипт делает ad-hoc подпись, поэтому отдельного «ПКМ -> Открыть»
обычно не требуется.

## Тесты

```bash
swift test
```

## Где лежат данные

- Кэш комментариев: `~/Library/Application Support/YTCommentsAnalyzer/<videoId>.json`
- API-ключ: `UserDefaults` приложения

## Заметки

- Комментарии YouTube имеют 2 уровня: корень треда и плоский список ответов.
- Грузятся все верхнеуровневые комментарии и все ответы (полный офлайн-поиск).
  Каждый запрос к API стоит 1 единицу квоты; дневной лимит по умолчанию 10000.
- Саммари v2 анализирует все загруженные комментарии порциями и выдаёт 2–3 коротких абзаца с проверяемыми источниками.
- Чат ищет по всем комментариям с перефразировками, при необходимости раскрывает треды и делает дополнительный поиск. Обзорные вопросы обрабатываются полным проходом; его можно принудительно включить переключателем «Все комментарии».
- Подсчёты выполняются по уникальным ID с явным критерием. Смысловая классификация моделью может ошибаться.
- Прогресс, отмена и промежуточные результаты работают в памяти; сохранённые JSON не мигрируются.
- [Как устроен анализ v2: схемы, алгоритмы, ограничения](docs/analysis-v2.md).
- Для Ollama: ollama.com → `ollama pull llama3.1:8b`; подключение через «API / Ollama». Для многоэтапного анализа требуется модель, надёжно возвращающая JSON.

## Подписка ChatGPT

В настройках выберите «Подписка ChatGPT» → «Продолжить с ChatGPT».
В браузере войдите в свой аккаунт и разрешите приложению использование подписки.
Загрузите модели ChatGPT и выберите доступную модель. Настройки сохраняются автоматически.
Уровень размышления задаётся явно: low, medium (по умолчанию), high, xhigh или max;
поддержка зависит от модели. Выбранный уровень применяется к саммари и чату.
Саммари запрашивается в 2–3 коротких абзацах: 120–160 слов, не более 180.
Саммари и чат по комментариям используют выбранную модель и лимиты подписки;
отдельный API-ключ OpenAI и установка Codex не нужны. Комментарии и вопросы
передаются в OpenAI. Автоматического перехода на платный API нет.

Поддерживается один аккаунт/рабочее пространство на установку. Сессия хранится
в macOS Keychain и автоматически обновляется. «Выйти» отзывает сессию и удаляет
локальные токены, сохраняя регистрацию для повторного входа. Доступ приложения
и лимиты можно проверить в настройках ChatGPT. API/Ollama доступны через
переключатель подключения.

Интеграция использует официальный Sign in with ChatGPT для локальных приложений
и Responses API. Функция находится в preview: доступность зависит от аккаунта,
рабочего пространства и региона. Сам факт наличия подписки не гарантирует доступ.
Документация: https://developers.openai.com/siwc/token-sharing-open-source

Если локальные Command Line Tools не находят Swift Testing, проверка:

```bash
swift test --sdk /Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk \
  -Xswiftc -load-plugin-library \
  -Xswiftc /Library/Developer/CommandLineTools/usr/lib/swift/host/plugins/testing/libTestingMacros.dylib
```
